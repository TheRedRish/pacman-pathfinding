# Pacman Pathfinding

Dette projekt demonstrerer pathfinding-algoritmer i et Pacman-inspireret miljø med en backend og frontend, som gør det muligt at visualisere hvordan Pacman navigerer gennem et kort.

## Brug af AI
Udviklingsprocessen har benyttet ChatGPT Codex til at assistere med kodning, strukturering og dokumentation, så løsninger og beskrivelser hurtigt kunne udformes.

## Installation og start
1. Sørg for at have Node.js installeret.
2. Gå til backend-mappen og installer afhængigheder: `cd backend && npm install`.
3. Start serveren: `npm start` (kører som standard på http://localhost:3000 og serverer frontend-filerne). Brug `npm run dev` for automatisk genstart under udvikling.
4. Åbn http://localhost:3000 i din browser for at prøve pathfinding-visualiseringen. Data for benchmarks og kort gemmes lokalt i `backend/data/`.
